# BepisHotReload
[![Thunderstore Badge](https://modding.resonite.net/assets/available-on-thunderstore.svg)](https://thunderstore.io/c/resonite/)

A [Resonite](https://resonite.com/) mod that lets you hot reload BepInEx plugins from a `HotReload` folder without restarting the game. Plugins can be reloaded individually or all at once through BepisModSettings.

## Credits

The plugin loading code is derived from [BepInEx.Debug's ScriptEngine](https://github.com/BepInEx/BepInEx.Debug/blob/master/src/ScriptEngine/), which is licensed under LGPL-3.0.

## Installation (Manual)
1. Install [BepisLoader](https://github.com/ResoniteModding/BepisLoader) for Resonite.
2. Download the latest release ZIP file (e.g., `NepuShiro-BepisHotReload-1.0.0.zip`) from the [Releases](https://github.com/NepuShiro/BepisHotReload/releases) page.
3. Extract the ZIP and copy the `plugins` folder to your BepInEx folder in your Resonite installation directory:
   - **Default location:** `C:\Program Files (x86)\Steam\steamapps\common\Resonite\BepInEx\`
4. Start the game. If you want to verify that the mod is working you can check your BepInEx logs.
